# Etsy Jewelry Gemini Prompt

一个面向 Etsy 项链、手链、手镯、耳环、耳钉和戒指商品摄影的 Codex Skill，用于生成、诊断和迭代优化 Gemini 图像提示词。

它只输出文字提示词，不调用图片生成工具。产品参考图或完整产品规格至少提供一项；佩戴比例图和摄影风格图均为可选输入。

## 功能

- 严格锁定珠宝结构、材质、宝石数量和真实比例
- 按项链、手饰、耳饰和戒指选择专用构图与限制词
- 隔离产品、佩戴比例和摄影风格参考，避免参考图互相污染
- 支持暖棕暗调、皮肤质感、自然景深和宝石高光控制
- 诊断下巴入镜、手部抢画面、皮肤白点、吊坠变形和宝石过曝
- 每轮只修正最重要的 1–3 个问题

## 安装

复制 `skill/etsy-jewelry-gemini-prompt` 文件夹到 Codex Skills 目录：

```text
%USERPROFILE%\.codex\skills\etsy-jewelry-gemini-prompt
```

重新打开 Codex 任务后即可使用。

## 使用示例

只有产品图：

```text
使用 $etsy-jewelry-gemini-prompt，根据这张产品图生成一版短提示词。
要求暖棕暗调、单手、不露下巴、1:1。
```

提供产品图和佩戴比例图：

```text
使用 $etsy-jewelry-gemini-prompt。图一是产品图，图二只参考佩戴大小、
链长和构图。生成完整版提示词。
```

提供三张参考图：

```text
使用 $etsy-jewelry-gemini-prompt。图一锁定产品，图二参考佩戴比例，
图三参考皮肤、光线和摄影风格。输出短版。
```

分析生成结果：

```text
使用 $etsy-jewelry-gemini-prompt 看看这张生成图，只修改最主要的问题。
```

戒指示例：

```text
使用 $etsy-jewelry-gemini-prompt，根据图一戒指产品图生成暖棕暗调佩戴图提示词。
保持戒面、爪镶、宝石数量和戒臂宽度，单手自然展示，不要叠戴其他戒指。
```

耳饰示例：

```text
使用 $etsy-jewelry-gemini-prompt，根据产品图生成耳环佩戴图短版提示词。
头发收至耳后，只露耳朵和局部侧脸，完整展示耳环，不出现完整正脸。
```

## 输入规则

| 输入 | 是否必需 | 用途 |
|---|---:|---|
| 产品参考图 | 二选一 | 产品结构、材质、宝石、扣件和比例 |
| 完整产品规格 | 二选一 | 类型、毫米尺寸、材质、宝石、扣件或镶嵌结构 |
| 佩戴比例参考图 | 否 | 佩戴位置、视觉大小、动作和构图 |
| 摄影风格参考图 | 否 | 肤色、光线、色彩和摄影质感 |

没有佩戴比例图时，Skill 不会声称知道精确尺寸；没有风格图时，默认使用暖棕暗调珠宝摄影。
