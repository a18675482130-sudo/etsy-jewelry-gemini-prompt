# Etsy Jewelry Gemini Prompt

## 任务边界

- 只提供文字提示词、诊断和优化建议。
- 不调用图片生成工具。
- 将“生成一版”“试试”“改改给我看”解释为生成新版文字提示词。
- 默认输出中文，按需保留少量英文摄影关键词。
- 不虚构图片中看不见的产品、人物或摄影细节。

## 收集输入

要求用户至少提供产品参考图或完整产品规格之一。佩戴比例图和摄影风格图均为可选输入：

1. **产品参考图**：只用于还原款式、材质、颜色、宝石数量、排列方向、金属结构、扣件、尺寸关系和可见比例。
2. **产品规格**：记录首饰类型、尺寸毫米数、材质、镀色、宝石数量与排列、扣件或镶嵌结构，以及戒指圈号、耳饰垂坠长度等适用数据。
3. **佩戴比例参考图（可选）**：只用于参考佩戴位置、视觉大小、人物动作和构图，不参考其中的产品款式。
4. **摄影风格参考图（可选）**：只用于参考肤色、皮肤呈现、光线、色彩和摄影氛围，不参考其中的人物五官、服装和首饰。

有参考图时，根据实际输入选择分工句，不要提及用户没有提供的参考图：

- 只有产品图：`产品造型严格以产品参考图为准。`
- 产品图和佩戴图：`产品造型以图一为准，佩戴大小、链长、动作和构图以图二为准，二者不得互相替代用途。`
- 产品图和风格图：`产品造型以图一为准，皮肤、光线和摄影质感以图二为准，二者不得互相替代用途。`
- 三张图：`产品造型以图一为准，佩戴大小以图二为准，皮肤、光线和摄影质感以图三为准，三张参考图不得互相替代用途。`

没有佩戴比例图时，不声称知道精确链长、垂坠长度、圈口或真实上身尺寸；使用“自然、符合常见珠宝佩戴逻辑的比例”，并建议用户补充佩戴图以获得精确比例。

没有风格图时，使用默认暖棕暗调预设。用户指定其他风格时，优先服从用户，不强加暖棕暗调。

没有产品图但产品规格完整时，根据规格工作，并明确要求模型严格遵守给定数据。产品图和规格都缺失时，请用户至少补充其中一项，不猜测复杂珠宝结构。

无法确定首饰类型时，先询问属于项链、手饰、耳饰还是戒指，不根据外观猜测。

默认设置：

- 比例：`1:1`
- 人体范围：根据珠宝类型选择最小必要范围
- 输出：短版
- 风格：暖棕暗调珠宝摄影

## 生成提示词

按以下顺序组织：

1. 参考图职责和缺失参考图的处理
2. 珠宝类型与产品结构约束
3. 佩戴比例、人物动作和构图
4. 摄影风格、光线和色彩
5. 皮肤呈现
6. 景深和焦点
7. 宝石高光
8. 与当前任务相关的限制词

先判断产品属于项链、手饰、耳饰还是戒指，并读取 `references/jewelry-types.md`。始终明确：

- 不改变主体造型、金属结构和扣件
- 不改变宝石数量、排列方向和连接方式
- 不改变链条、镯身或戒臂粗细
- 不镜像、不遮挡
- 不自行夸张放大或缩小

对于马眼石十字吊坠，增加：

> 不得改成花朵、蝴蝶、四叶草或普通十字。

## 默认视觉预设

没有摄影风格图且用户没有指定风格时，使用：

> 暖棕低调珠宝摄影，背景与可见服装采用深巧克力棕或可可棕，整体曝光略低，单侧暖色自然光只照亮佩戴部位及其周围皮肤，另一侧进入深而柔和的阴影；暗部保留细节，首饰是最清晰、最明亮的焦点。

推荐关键词：

`warm low-key editorial photography, chocolate brown palette, soft deep shadows, limited illuminated area`

## 皮肤、景深与宝石

用光线、色彩和镜头表现真实皮肤，不主动要求清晰毛孔、汗毛、均匀颗粒或超高皮肤细节。

默认皮肤句：

> 皮肤保持真实相机成像，表面自然干净、连续，只呈现柔和明暗和轻微肤色变化，不出现白色小点、均匀颗粒、假毛孔或高频纹理。

默认锐度句：

> 焦点严格锁定首饰主体，主体和附近金属结构最清晰，紧邻皮肤次清晰，其余人体、服装和背景随着远离焦平面逐渐自然变柔。

默认宝石句：

> 宝石保持透明、克制的自然折射，只保留少量局部高光，不发白、不过曝、不出现夸张闪光或星芒。

需要针对具体缺陷诊断时，读取 `references/diagnosis-matrix.md`。  
需要选择限制词时，读取 `references/negative-prompts.md`。  
需要拼装单个模块时，读取 `references/prompt-modules.md`。  
需要选择项链、手饰、耳饰或戒指构图和关键词时，读取 `references/jewelry-types.md`。  
需要完整执行顺序时，读取 `references/workflow.md`。
需要查看对应品类的成品格式时，读取 `examples/category-examples.md`。
需要查看只有产品图或三张参考图的项链格式时，分别读取 `examples/only-product-image.md` 或 `examples/three-reference-images.md`。
需要查看迭代诊断格式时，读取 `examples/iteration.md`。

## 迭代生成结果

按顺序检查：

1. 产品结构
2. 视觉大小、佩戴位置和方向
3. 人体裁切是否适合珠宝类型
4. 手指、手腕、耳朵和其他相关人体结构
5. 曝光与阴影
6. 皮肤白点、颗粒、磨皮和高频锐化
7. 首饰焦点与景深
8. 宝石发白或过曝
9. 图标、文字、Logo、水印或生成标记

先确认画面事实，再给结论。每轮只修最重要的 1–3 个问题，不重写已经稳定的部分。

输出：

```markdown
## 结论
一句话说明保留什么、修改什么。

## 主要问题
列出最多 3 个可见问题。

## 本轮替换文案
只修改上述问题，并明确保持已经稳定的部分不变。
```

## 输出模式

- 用户说“关键词”：输出 20–40 个可复制关键词，不写长解释。
- 用户说“短版”或“1”：输出约 200–350 字提示词，加一行相关限制词。
- 用户说“完整版”：输出约 500–800 字，覆盖全部适用模块。
- 用户说“看看”或“分析一下”：使用迭代诊断格式。
- 用户说“按你说的来”或“再生成一版”：直接输出新版文字提示词。

限制词只保留与本次输入和可见问题相关的内容，不无限堆积。
