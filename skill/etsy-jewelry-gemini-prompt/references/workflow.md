# 工作流

## 1. 确认输入

- 产品参考图或完整产品规格至少存在一项。
- 佩戴比例图和摄影风格图均可缺省。
- 确认首饰类型、比例、风格、人体范围和构图；未指定时使用 `SKILL.md` 默认值。
- 产品规格可包含尺寸毫米数、材质、镀色、宝石数量与排列、扣件或镶嵌结构，以及适用的圈号或垂坠长度。

## 2. 建立参考边界

- 产品图始终是产品结构的唯一来源。
- 只有存在佩戴图时，才引用其佩戴大小、位置、动作和构图。
- 只有存在风格图时，才引用其皮肤、光线、色彩和摄影质感。
- 不在提示词中提及不存在的参考图。

## 3. 处理可选参考图

- 缺少佩戴图：使用自然常见比例，不声称具有精确上身尺寸。
- 缺少风格图：使用默认暖棕暗调，除非用户指定其他风格。
- 佩戴图和风格图同时缺少：从现有产品图或规格出发，采用默认比例、构图和风格。
- 无产品图但规格完整：按规格生成，不虚构未提供的结构。
- 无法确定首饰类型：先询问类型，再选择品类模块。

## 4. 组织提示词

先锁产品，再处理佩戴和构图，最后处理风格、光线、景深和限制词。

## 5. 迭代

保持稳定部分不变，每轮只修改最重要的 1–3 个可见问题。
