# 生成结果诊断矩阵

| 现象 | 可能原因 | 修改策略 |
|---|---|---|
| 胸前均匀白色小点 | 模型用颗粒模拟真实皮肤 | 禁止 `white skin dots`、`uniform micro dots`；降低皮肤微对比 |
| 皮肤像砂纸 | 毛孔或超真实皮肤词触发过度细节 | 删除毛孔、汗毛、微纹理和超真实皮肤词 |
| 皮肤像塑料 | 美容光或无瑕皮肤描述过强 | 改为自然哑光、轻微肤色变化和单侧自然光 |
| 整片胸口同样锐利 | 缺少焦点层级 | 焦点锁定吊坠；胸前和手部自然变柔 |
| 宝石发白 | 高光或闪耀描述过强 | 使用克制高光和自然折射 |
| 暗调变成死黑 | 只要求低调和深阴影 | 增加暗部保留细节 |
| 下巴仍出现 | 负面约束太泛 | 规定画面顶部裁切在颈部中上段 |
| 手抢画面 | 手部占比过大 | 手部下移、减少占比、不触碰吊坠 |
| 吊坠变形 | 其他参考图污染产品结构 | 强化产品图是唯一产品结构来源 |
| 吊坠变花朵或蝴蝶 | 马眼石十字语义歧义 | 明确禁止花朵、蝴蝶和四叶草 |
| 标记或水印 | 模型或平台自动添加 | 禁止图标、生成标记、文字、Logo和水印 |
| 手链悬浮或陷入皮肤 | 缺少自然贴合约束 | 要求自然腕围、保留少量皮肤间隙、不悬浮不嵌入 |
| 手镯被自动叠戴 | 模型补充搭配饰品 | 明确只保留产品图中的单件手饰 |
| 耳饰被头发遮挡 | 发型和产品焦点冲突 | 头发收至耳后，完整露出耳饰结构 |
| 耳饰数量或左右不一致 | 未说明单只或成对展示 | 先固定展示数量，再锁定左右方向和对称关系 |
| 戒指悬浮、转向或换手指 | 缺少贴合、方向和佩戴位置 | 固定手指、戒面朝向和自然贴合指根 |
| 手指出现增生或融合 | 手部近景结构错误 | 使用自然放松手势，禁止多指、少指和融合手指 |
